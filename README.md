# TITAN STORE — One Click Firebase Deploy

1. Extract this ZIP.
2. Double-click `DEPLOY.bat`.
3. The script installs Node.js LTS and Firebase CLI if needed.
4. A Google/Firebase login window opens — complete the login.
5. The script selects `titan-brand` and deploys Hosting + Firestore rules + indexes.
6. It opens the live website when deployment succeeds.

Live URLs:
- https://titan-brand.web.app
- https://titan-brand.web.app/admin

The script cannot enter your Google password for you; the browser login is the only manual account step.
